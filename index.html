Wearable Gesture Controller using TinyML

A glove that controls presentations wirelessly by acting as a Bluetooth keyboard, so the computer needs no extra software.

  • Trained a neural network in Edge Impulse on MPU6050 motion data to classify swipe and wrist-twist gestures on an ESP32.
  • Added filtering so accidental movements don't trigger slide changes.
  • Ran a within-subjects user study comparing gesture and keyboard input; every participant preferred the glove.

GroupEmbedded · Assistive tech

Smart Blind Stick: Low-Cost Embedded Mobility Aid

An Arduino-based smart cane that helps visually impaired users move more independently without relying on a smartphone.

  • Detects floor-level obstacles, surface water and low light, with a distinct vibration pattern for each hazard and a priority rule so only one cue plays at a time.
  • A 433 MHz RF remote finds a misplaced cane, and a one-button SOS handles emergencies. Runs on a rechargeable Li-ion pack.

My contributionBuilt the GPS/GSM SOS module. It sends the user's live location as a Google Maps link by SMS to a caretaker, falling back to the last known position, and I tested the full workflow outdoors.

  • Arduino Nano
  • SIM800L GSM
  • GPS (UART)
  • HC-SR04
  • 433 MHz RF
  • C/C++

IndividualMobile · Data analysis

Mental Wellbeing & Digital Habits Tracker

An Android app that pairs daily mood check-ins with consent-based screen-time tracking to study how phone habits relate to wellbeing.

  • Built with Kotlin, Jetpack Compose and Room.
  • A Python pipeline uses mixed-effects models to separate within-person from between-person effects, validated on synthetic data.
  • Privacy by design: informed consent, data minimisation, on-device storage and pseudonymised export.
